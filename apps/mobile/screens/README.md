# Screens 📺

Screens are collections of the various screens that make up Pathize. In a specific folder, you may find the screens associated with a specific feature or function (onboarding, activities, account management, etc.), as well as any associated *navigators* that are involved with managing a group of screens.

If you need to add a new screen, it should probably go in either an existing folder or a folder or a new folder should be created. If you need to create a new component that is associated with a screen, it should go in the *components* folder associated with a feature. If no feature seems to match, it might be advisable to make a new one.
