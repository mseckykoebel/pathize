# Features ✨

Features are groupings of related components, services, types, and helper functions that serve a related purpose. Features do not import from other features, but can import from core utilities, types, hooks, and layouts.

## Rules of thumb 👍

1) Do not use types, services, hooks, or components outside of the respective feature folder. If it is used elsewhere, move it to the root types, services, hooks, etc. folder that is most appropriate.
